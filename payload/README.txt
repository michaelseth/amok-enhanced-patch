AMOK - Portable 4K enhanced build

GETTING STARTED
Double-click Play-Amok.cmd to play.
Keep the Game folder beside Play-Amok.cmd. Move this whole folder together
when copying it to another Windows 10/11 PC. No installation is needed.
Use a writable folder. Your original game files were copied, not modified.

DISPLAY
The game renders at 3840 x 2160 and scales to the desktop display size.
It includes the confirmed terrain precision and alignment repairs, extended
terrain/sprite/polygon range, gentle distance fog, smaller HUD, corrected
camera overlays, and improved frame delivery. Presentation is capped at
60 FPS; actual performance depends on the computer and scene.

XBOX / XINPUT CONTROLLER
Left stick: forward/back and strafe left/right
Right stick: turn left/right
Left stick click: toggle running
Right stick click: cycle camera distance
RT or RB: minigun
LT or X: missile
Y: heavy weapon
A: bomb / select menu item
B: Escape / back / skip
View: map
Start: end mission and return to menu (Shift + Escape)
LB: original Alt modifier
D-pad: arrow keys / menu navigation

KEYBOARD
Escape opens the menu from the opening screen or backs out of menus.
Enter selects. Shift + Escape ends a mission and returns to the menu.
F1 cycles camera distance. Original keyboard controls remain available.

PACKAGE NOTES
The game, enhancement helper, display wrapper and game assets are included.
The launcher uses only paths relative to its own folder, so the whole folder
can be moved. The cnc-ddraw license is included in Game.
This is the player-confirmed build from 10 October 2026. A full playthrough
has not yet been tested. No development tools are required to play.
